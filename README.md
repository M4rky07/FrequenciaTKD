# FrequenciaTKD

📱 Aplicativo de controle de frequência para academias de Taekwondo

## Funcionalidades
- Cadastro de alunos
- Turmas
- Chamada
- Histórico
- Frequência mensal/anual
- Backup e restauração
- Funcionamento offline

## Tecnologias
- React Native
- Expo
- Expo Router
- AsyncStorage
- JavaScript
